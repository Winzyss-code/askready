THESIS: Your rehearsal is game tape: the coach marks the moment, you run it again, the board shows what changed.

OWN-WORLD: Film Room. STORY: Set up the conversation in a few answers -> face the manager (one disc whose geometry changes: idle, listening, thinking, speaking) -> coach marks three moments in your own words (you said / say this instead / why) -> run the same objection again -> the board shows attempt 1 against attempt 2 with deltas.
